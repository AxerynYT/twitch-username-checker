# Twitch Username Checker

#checker #usernamechecker #twitchchecker #namechecker #twitch #username #availability #python #script #tool #osint #graphql #api #multithreading #ratelimit #automation #opensource #cli

A fast Twitch username availability checker.

## Features

- No Twitch Developer account needed
- Multi threaded checking
- Rate limit aware
- Saves available usernames to a text file
- Progress reporting
- Supports random username generation by length and character mode

## Requirements

- Python 3.8+
- `requests`

Install dependencies:

```bash
pip install -r requirements.txt
